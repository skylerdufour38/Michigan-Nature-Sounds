# Michigan Nature Sounds

Interactive wildlife sound explorer created for:

Ann Arbor Hands-On Museum

## Features

- Mammal sounds
- Bird sounds
- Insect sounds
- Wildlife images
- Scientific names
- Audio playback

## Categories

🐾 Mammals

🐦 Birds

🪲 Insects

## Technology

- HTML5
- CSS3
- JavaScript
- JSON
- GitHub Pages
- GitHub Codespaces

## How It Works

Choose a category → select an animal → view information → play sound.
